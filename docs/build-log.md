# Build log — Lecture 01

A record of how `lectures/01-anatomy-of-play` got to its current state, kept mainly
so Lecture 02 doesn't have to rediscover any of it. Ordered by what changed, not by
when — the technical findings at the end are the part worth re-reading.

## Where the deck came from

Built from `course/CS464-Course-Outline.docx`. The outline supplied the CLOs, the
Bloom levels, the grading split, the credit hours and the fifteen-week shape; the
lecture content around it (magic circle, MDA, Bartle) was written for the slot.

The deck is generated by `lectures/01-anatomy-of-play/src/build_doc.py`, which emits
the whole document as JSON and writes it into the `#bento-doc` block of the HTML
file. That was a deliberate choice early on: the deck is large enough that
hand-editing JSON would have been unmanageable, and a generator makes global changes
(a palette shift, a font swap, renumbering) one-line operations.

## Content added after the first pass

- Richard Bartle as a person, not just a taxonomy — MUD1, the 1996 paper, Essex.
- "What is a game?" with the Salen & Zimmerman definition and the five parts.
- The magic circle: Huizinga's origin, the porous-boundary critique (Castronova),
  and a separate slide on what to decide on purpose when designing one.
- Rules of play — constitutive, operational, implicit — with chess as the running
  example so all three are visible side by side.
- Finite and infinite games (Carse), tied to the final project: aim for a great
  finite game, not an ambitious infinite one you won't finish.

## Design changes, and why

**The 15-week arc was rebuilt from scratch, twice.** The first version was a flat
horizontal rule with four cards hanging off it. It was legible and completely inert.
The second version added a curved dashed path with marching dashes, which helped but
kept the same fundamental shape. The current version throws the line away: four
glowing act-nodes climb a rising trajectory, and the rise carries meaning — the gaps
widen as the Bloom verbs go from "understand" to "create". Page one lights only acts
I and II; page two morphs the other two from dark husks into lit discs. The reveal is
a property change on shared ids, not new elements sliding in.

**The magic circle became an actual orbit.** It was two static ellipses. It is now a
marching dashed ring — dashed and moving because the boundary is maintained by
agreement, not physics — with the game glowing at the centre, players circling
inside, and grey motes still turning outside in ordinary life. The diagram now
argues the point instead of illustrating it.

**Bartle's taxonomy became a real diagram.** It had been four cards in a grid with
floating axis labels. It is now a proper matrix with drawn axes, and each quadrant
expands in place into a full brief via a hidden state slide. See the pattern note in
`deck-design-system.md`.

**The MDA trio lost three large empty boxes.** Each of the three deep-dive slides
had "NEXT / Dynamics"-style panels that were mostly air and read as unfinished. They
were replaced with a three-step chain whose highlight walks down across the slides.

**Typography was the single biggest visual win.** The deck originally named
`'Trebuchet MS'` and `'JetBrains Mono'` in its font stacks and carried neither. That
falls back silently — and it looks correct on the machine of whoever has the fonts
installed, which is exactly why it went unnoticed. Instrument Sans and Space Mono are
now embedded in the document as woff2 data URIs.

**Glow and gradient were added throughout.** Comparing against the polished Bento
templates, the clearest gap was that the reference decks put a `shadow` on nearly
every accent shape and a `fillGradient` on discs and badges, and this deck used
neither. On a dark ground that is most of the difference between a slide and a
designed slide.

**Cover, both section breaks and the closing slide** all gained the orbit motif, so
the deck opens and closes on the same image.

## Things that did not work

- **A photograph of Richard Bartle could not be fetched.** Wikipedia file URLs are
  cache-only through the available fetch tooling, and the University of Essex faculty
  image was refused by the network egress policy. The slide uses an "RB" monogram in
  the deck's own visual language instead. If a properly licensed photo turns up,
  drop it in and swap the monogram.
- **"Click anywhere to go back" as a full-canvas invisible rect.** See below.

## Technical findings

These are Bento behaviours that cost time to discover.

**A freshly downloaded Bento template has an empty `#bento-doc` block.** The showcase
deck you see when you open it is minted by the app's own JavaScript on first open. So
you cannot read the example content by grepping the file — you have to open it in a
browser and read `window.bento.doc`. The four polished templates in `templates/` are
different: those are real saved decks and their JSON is in the file.

**`shadow` and `fillGradient` are undocumented but fully supported.** Neither appears
in the schema at bento.page/agents.md, but every official template uses them heavily.
`shadow` takes `{blur, color}` for a glow, or `{x, y, blur, color}` for an offset
shadow. `fillGradient` takes `{angle, stops:[{at, color}]}`.

**Orbits are two primitives.** A dashed ellipse with `fx.loop.dash-march` gives a ring
whose dashes crawl round the rim. A body orbiting it is an ellipse with
`fx.loop.motion-path` whose path is a polyline approximation of a circle expressed as
offsets *relative to the element's resting position* — so the element must be placed
at its starting angle and the path generated from there. Never put an `fx.enter` on a
motion-path element; they fight over the same transform.

**Don't make a full-canvas invisible rect a link target.** The player styles link
targets with a pill affordance, so a 1280×720 hit rect draws an enormous
accent-coloured ellipse across the whole slide whenever the cursor is over it. It
looks like a rendering bug and it is very hard to trace. Use a small visible button.

**charts-lite honours `"label": false` and `"legend": false` as literal booleans.**
The object form `{"show": false}` is silently ignored, which showed up as clipped
leader-line labels on the grading donut.

**Elements with a morph partner skip `fx.enter` and `fx.countUp`.** Setting them
anyway earns an `overridden-enter-fx` warning. Build helpers with a "no fx" variant
for an element's repeat appearance.

**`{{page:2}} / {{pages}}` beats hand-numbered footers.** Page tokens resolve at
render time and exclude hidden state slides, so adding the four Bartle expansions
left the visible count at 35 with no renumbering.

**There is no per-bar chart animation.** The two bar charts are hand-built from rects
and text with a staggered `fx.enter` per bar, because charts-lite exposes no grow
animation and per-item bar colours are unsupported.

## How it was checked

`window.bento.validate()` reports 0 errors and 0 warnings. That is necessary and not
sufficient — it does not see overlapping elements, a card that is mostly air, or a
chart label clipped by its container. Every slide was rendered headless and looked
at, and most of the fixes above came from the screenshots rather than the validator.
Contact sheets of the current state are in the lecture's `preview/` folder.
